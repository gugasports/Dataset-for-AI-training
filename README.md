# Dataset-for-AI-training
Criação uma base de dados (dataset) para o treinamento de um algoritmo baseado em Redes Neurais Artificiais. Para essa tarefa será criado ao menos duas classes de objetos com no mínimo 100 imagens para cada uma delas. Esse dataset servirá como base para os projetos desenvolvidos ao longo de toda a trilha, em diferentes projetos.  Projeto DIO
